# BitDragon - Backend

## Descrição

Backend da aplicação **BitDragon**, um gerenciador de campanhas de RPG em desenvolvimento.

## Status

⚠️ **Projeto em Andamento**

Este projeto está em fase de desenvolvimento. Funcionalidades podem mudar, e nem todos os endpoints estão finalizados.

## Tecnologias

- **Node.js** com Express
- **TypeScript**
- **Prisma** ORM
- **PostgreSQL** (banco de dados)
- **Docker** para containerização



## Estrutura do Projeto

```
Back/
├── src/
│   ├── controllers/      # Controladores das rotas
│   ├── routes/           # Definição de rotas
│   ├── services/         # Lógica de negócio
│   ├── schemas/          # Validação de dados
│   ├── middleware/       # Middlewares personalizados
│   └── index.ts          # Entrada principal
├── prisma/
│   ├── schema.prisma     # Modelo de dados
│   └── migrations/       # Histórico de migrations
└── package.json
```

## Funcionalidades Principais

- ✅ Autenticação de usuários
- ✅ CRUD de campanhas
- ✅ Upload de imagens de campanhas
- 🔄 Gerenciamento de participantes
- 🔄 Sistema de quests
- 🔄 Journal/Notas de campanha
